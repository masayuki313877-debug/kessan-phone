左メニューの 「📱 スマホから取り込み」 に、取り込み方のボタンが並んでいます。

ボタン使うとき
📋 貼り付けて取り込むLINEなどで文字を受け取ったとき（この画面で Ctrl+V でも同じ）
📂 CSVファイルを選ぶCSVファイルが手元にあるとき。いくつかまとめて選べます
📥 まとめて取り込むダウンロードフォルダやGoogleドライブのフォルダにCSVがたまっているとき。初回だけフォルダを選びます
（ドラッグ）CSVファイルを画面にドラッグして放す
  1. 決算帳を起動し、「ファイルを開いて続きから」 を押す（右上のランプが緑になったのを確認）
  2. 上のどれかで取り込む内容を読み込む
  3. 「取り込む内容の確認」に 新しく取り込む取引だけが一覧で出ます（取り込み済みの分は隠れています。「取り込み済みも表示する」で見られます）

確認画面の「状態」の意味

表示意味どうする
新しく取り込みますこれから帳簿に追加される取引そのままでOK
取り込み済み（とばします）前に取り込んだことがある取引。二重には入りませんそのままでOK
科目がありません決算帳にまだ無い科目名（例：車両費）「経費として自動で追加」にチェックを入れて取り込む。打ち間違いなら CSVを直す
対象の年のデータがありません年をまたいだ取引（例：2027年1月の入力）決算帳で「次年度繰越」をしてから、もう一度取り込む
日付・科目・金額のどれかが正しくありません2月30日のような日付、金額が空・文字などCSVの該当の行を直す
📝 表の左端の「行」は、Excelで開いたときの行番号です 例えば「行 5」が「正しくありません」なら、CSVをExcelで開いて 5行目 を見れば該当の取引です（1行目は見出し）。
⚠ 「科目を経費として自動で追加」について 追加された科目は、損益計算書の空欄㉕〜㉚に印字されます（6つまで）。「消耗品費」を「消耗品」と打ち間違えたような場合に自動追加すると、別の科目が増えてしまいます。見慣れない科目名が出たら、チェックを外してCSVを直してください。

8. ExcelでCSVを開く・直す

取り込む前に内容を直したいとき（金額の打ち間違い、メモの追加など）は、CSVをExcelで開いて直せます。

  1. スマホ入力_○○.csv を ダブルクリック（Excelで開きます）
  2. セルを直す
  3. F12（名前を付けて保存）→ ファイルの種類を 「CSV（コンマ区切り）(*.csv)」（新しいExcelなら「CSV UTF-8」でも可）→「保存」
  4. 「一部の機能が失われる可能性があります」と出たら 「はい」（CSVには色や書式が保存されないという意味で、中身は問題ありません）
  5. Excelを閉じるときに「変更を保存しますか？」と聞かれたら、もう保存済みなので「保存しない」でOK
  6. 決算帳で、そのCSVを取り込む

Excelで開いたときに気になる点（問題ありません）

見え方説明
日付が 2026-09-17 から 2026/9/17 に変わるExcelの表示のしかたです。そのまま保存してOK。決算帳はどちらも読めます
保存し直すとファイルの文字コードが変わるExcel 2013 の「CSV（コンマ区切り）」は Shift-JIS という形式で保存されます。決算帳は自動で見分けて読めるので気にしなくて大丈夫です
ID列（F列）に英数字が並んでいる二重取り込みを防ぐ目印です。消したり書き換えたりしないでください
✕ やってはいけないこと
  • 1行目（見出し）を消す・書き換える →「見出しが見つかりません」になって取り込めません
  • ID列（F列）を消す・書き換える → 前に取り込んだ取引が、別の取引とみなされて二重に入ります
  • 「Excel ブック（*.xlsx）」で保存する → CSVではないので取り込めません。必ず「CSV」を選んでください
  • 科目名を略す（「消耗品費」→「消耗品」など）→「科目がありません」になります
⚠ 文字化けして読めないとき ダブルクリックで開いて「譌･莉倥…」のような文字になる場合は、Excelの 「データ」タブ →「テキストファイル」 から開き、文字コードで 「65001 : Unicode (UTF-8)」 を選んでください。スマホアプリから出たCSVは通常そのまま開けます。

9. ExcelでCSVを一から作る

スマホに入れ忘れた分をまとめて入れたいときや、レシートの束をExcelで一気に打ちたいときに使えます。

  1. 決算帳の「📱 スマホから取り込み」→ 「Excel入力用のひな形CSV」 を押す → スマホ入力_ひな形.csv が保存される
  2. ダブルクリックでExcelで開く（見出しと、例が2行入っています）
  3. 例の2行を消して、2行目から取引を1行ずつ入力
  4. ID列（F列）は空のままでOK
  5. 「CSV（コンマ区切り）」で保存 → 決算帳で取り込む
📝 入力例（レシートの束をまとめて入れる）
行A 日付B 借方科目C 貸方科目D 金額E 摘要F ID
1日付借方科目貸方科目金額摘要ID

⚠ ID列が空の行を、あとで直して取り込み直すと二重になります ID列が空の行は、「日付・科目・金額・摘要」の中身で同じ取引かどうかを見分けます。そのため、一度取り込んだあとに金額やメモを直してもう一度取り込むと、別の取引として追加されます。
取り込んだあとに間違いに気づいたら、CSVではなく 決算帳の仕訳日記帳で直接直してください。

10. 二重に取り込まれないしくみ

CSVの行どうやって見分けるか例
ID列に目印がある
（スマホから出たCSV）		IDが同じなら、中身をExcelで直していても「取り込み済み」同じCSVを2回取り込む → 2回目は全部「取り込み済み」
ID列が空
（Excelで手入力した行）		日付・借方・貸方・金額・摘要が全部同じなら「取り込み済み」同じ日に同じガソリン代を2回入れた行 → 別々の取引として2件とも入る（1ファイルの中で数えるため）

取り込んだ取引には、仕訳の中にこの目印が記録されています。取り込み済みかどうかは、その年だけでなく決算帳に入っている全部の年で調べます。

11. 取り込めないとき（Q&A）

Q. 「CSVの1行目（見出し）に…が見つかりません」と出る

1行目が 日付,借方科目,貸方科目,金額,摘要,ID になっていません。Excelで開いて1行目を直すか、「ひな形CSV」から作り直してください。見出しの並び順は入れ替わっていても読めます。

Q. 「スマホ入力のデータではないようです」と出る

別のファイル（決算帳のデータファイル 決算データ_○○.json など）を選んでいます。スマホ入力_○○.csv を選んでください。

Q. 「このCSVはパソコンの仕訳日記帳から出力したもの」と出る

決算帳の「仕訳日記帳 → CSV出力」で作ったCSVを選んでいます。同じ帳簿に取り込むと、すでに入っている取引が二重に入ります。スマホから来たCSVを選び直してください。

Q. 「科目がありません」がたくさん出る

多いのは 車両費 と 支払手数料 です。この2つは業種テンプレートを入れていないと決算帳にありません。「経費として自動で追加」にチェックを入れて取り込めばOKです。それ以外の見慣れない名前なら、打ち間違いを疑ってください（付録の科目名と見比べる）。

Q. 「CSVファイルを選ぶ」でファイルが見つからない

保存した場所を確認してください。LINEやメールから保存したものは 「ダウンロード」フォルダ に入っていることが多いです。ファイル選択画面の右下が「CSV」以外になっている場合は「すべてのファイル」にしてみてください。

Q. 「📋 貼り付けて取り込む」で「貼り付けの許可がありません」と出る

ブラウザがクリップボードの読み取りを止めています。その画面で Ctrl+V を押してください。同じように取り込めます。

Q. 「📥 まとめて取り込む」で「スマホから送ったCSVがありません」と出る

選んでいるフォルダにCSVが入っていません。「フォルダを変える」で、CSVを保存した場所（ダウンロード、Googleドライブの「決算帳_受け取り」など）を選び直してください。Googleドライブの場合は、同期が終わるまで少し待ってから押してください。

Q. 「📥 まとめて取り込む」を押すたびに「ファイルの表示を許可」と聞かれる

ブラウザの安全のしくみで、決算帳を起動するたびに1回聞かれます。「許可」を押してください。

Q. 取り込んだのに、損益計算書の数字が変わらない

ヘッダーの「会計年度」が、取り込んだ取引の年と違っていないか確認してください。取引は日付の年の帳簿に入ります。

Q. 間違えて取り込んでしまった

仕訳日記帳で該当の行をクリック →「この仕訳を削除」で消せます。まとめて戻したいときは「データ保存」画面の自動バックアップ（1日1回）から戻す方法もあります。

Q. スマホの入力が消えてしまった

スマホのブラウザの「閲覧データの削除」や機種変更で消えます。パソコンに取り込んだ分は決算帳に残っています。取り込み前の分は残念ながら戻せないので、週1回の取り込みを習慣にしてください。

12. 送ったあとの片付け

「⚡ サッと送る」で送った場合は、送った直後に「送信済」にしているので、下の2. だけでOKです。

パソコンに取り込めたことを確認してから、スマホの「📤 PCへ送る」画面の下で次の2つを押します。

  1. 「✓ 未送信 ○件を『送信済』にする」 … 一覧で薄い表示になり、次のCSVに入らなくなります
  2. 「🗑 送信済み ○件をこのスマホから削除」 … スマホの中が軽くなります（しばらく残しておいても大丈夫です）
⚠ 取り込み前に「削除」しないでください 削除した分はスマホから完全に消え、戻せません。必ず決算帳の仕訳日記帳に入っているのを見てから削除してください。「送信済」にするだけなら、あとで一覧から確認できます。

13. 間違えて登録したとき（直す）

現金で払ったつもりがカード払いだった——のような取り違えは、スマホでもパソコンでも、あとからまとめて直せます。どちらで直しても、やり直しの入力は要りません。

スマホで直す（まだパソコンに取り込んでいないとき）

やりたいこと操作
1件だけ直す「📋 一覧」で行をタップ → 金額・日付・メモを直す／科目・払い方はボタンから選ぶ → 「この内容で保存する」
まとめて直す「📋 一覧」で直したい行の左のチェックを入れる（何件でも）→ 上に出る青い帯の 「払い方を変える」（現金→未払金など）または 「科目を変える」 → 科目を選ぶ
まとめて消すチェックを入れて、青い帯の 「削除」
📝 例：現金で払ったことにした3件を、カード払いに直す 「一覧」で3件にチェック → 「払い方を変える」 → 「未払金」 を選ぶ。
表示が「車両費　現金」から「車両費　未払金」に変わります。

パソコンで直す（取り込んだあと）

やりたいこと操作
1件だけ直す仕訳日記帳や出納帳で行をクリック → 入力欄に読み込まれるので直して「修正を登録」
まとめて直す行の左のチェックを入れる（見出しのチェックで表示中すべて選択）→ 上に出る青い帯から選ぶ
・仕訳日記帳：「借方科目を変更」「貸方科目を変更」
・出納帳：「『現金』を別の科目に」「相手科目を変更」
摘要をまとめて直す青い帯の 「摘要を変更」
まとめて消す青い帯の 「削除」
📝 例：現金出納帳に入っている「カード払いだった3件」を直す
  1. 左メニューの 現金出納帳 を開く
  2. 間違えた3行の左のチェックを入れる
  3. 青い帯の 「『現金』を別の科目に」 を押す
  4. 科目の一覧から 「未払金」 を選んで「変更する」
これで3件とも「車両費 / 未払金」になり、現金出納帳から消えて、貸借対照表の未払金が増えます。翌月のカード引き落としのときに「未払金 / 普通預金」を入力すれば完了です。
⚠ 直すときの注意 ・借方と貸方が同じ科目になる行は、変更されずにそのまま残ります（メッセージで件数が出ます）
・金額・日付はまとめて変更できません（1件ずつ直してください）
・「決算・自動」と付いた仕訳（棚卸など）は選べません。決算整理の画面で直します
・スマホで直したあと、もう一度パソコンに送っても反映されません。取り込み済みの行は「取り込み済み」としてとばされるためです。パソコンに取り込んだあとは、パソコン側で直してください
